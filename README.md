# Living Atlas

An original, local-first, single-player open-world simulation.

## Hard constraints
See AGENTS.md and NON-NEGOTIABLES.md. No API keys, generative AI, cloud backend, or required online service. NPCs use deterministic authored game logic.

## Development
- Node.js 24+
- npm install
- npm run dev
- npm run typecheck
- npm test
- npm run build

## Current production stage
Foundation and Solara Bay vertical slice. Four connected compact regions are in the approved release scope. The first complete region is the production proving ground.

## Approved specification
See `docs/` for the public architecture decisions, production checkpoints, testing notes, and asset provenance.
