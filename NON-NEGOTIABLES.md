# Living Atlas — Non-Negotiable Production Guardrails

- ZERO API KEYS. No API key configuration, secret env vars, provider SDKs, or hidden cloud calls.
- ZERO GENERATIVE AI. Characters use hardcoded deterministic game AI only. No LLM dialogue or hosted inference.
- NO REQUIRED BACKEND. No Supabase, Firebase, custom API server, authentication, remote DB, analytics, or runtime network service.
- LOCAL SAVE. IndexedDB, versioned schema, manual save, autosave, resume, export, and import.
- END-TO-END PRODUCT. Boot, new game, play, interact, complete activities, save, reload, resume, and recover.
- OPEN-WORLD GAMEPLAY. Third-person movement, vehicles, residents, missions/activities, interiors, world simulation, and connected regions in approved scope.
- ORIGINAL IP. GTA is inspiration for open-world design, never permission to copy its content.
- LOW-END FIRST. Target Intel HD 520, i5-6200U, and 8 GB RAM. Profile actual hardware.
- VISUAL QA REQUIRED. Inspect localhost in a real browser. Capture fixed-view screenshots and check console/page errors, scene readability, motion, and performance.
- NO DRIFT. Every feature maps to the approved specification. Scope changes require a decision record and owner approval.
- RESEARCH PIPELINE. Use Exa + Firecrawl + TinyFish for web discovery, scraping, and browser-based verification. Parallel is excluded as redundant with Exa. RAG Atlas and Context7 remain the internal knowledge and current-docs sources.
- PRESERVE USER WORK. Standalone project. Do not overwrite either Ating Universe repository, RAG Atlas, or AI_Skills.
- NO UNAPPROVED PUSH/DEPLOY/DELETE. Local production is authorized. Remote publishing and destructive operations need separate approval.
